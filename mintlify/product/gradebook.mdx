---
title: "Gradebook"
description: "Set grade rules, work through scores, explain calculations, and release grades deliberately."
---

The gradebook brings course scores, grade rules, and student explanations into one place. Instructors can review released work separately from held work before making a change visible to students.

## Work through the grid

Each row is a student and each column is an assignment. Cells show scores and states such as missing, excused, held, and released. Use the keyboard to move between cells, edit a score, select a range, or fill a score down. Bulk changes show an Undo action and appear in grade history. An excusal requires a reason; that reason stays private to course staff.

The grid can filter by state, search for a student, and export a CSV. Open a student's detail panel to see the same grade calculation used for that student's released view. Staff can include held work in their own view without exposing it to students.

## Set up the calculation

In **Setup**, instructors choose category weights, drop rules, late penalties, missing-work treatment, and extra-credit limits. A setup check identifies rules that need attention. The **If you save** preview shows which current grades and letters would change. Scores themselves stay as entered; the saved rules change how they contribute to the course grade.

## Explain and release

The calculation trace lists each category's weight, earned and possible points, contribution, and relevant adjustments. Instructors can use the student panel to discuss how a grade was calculated.

**Release** opens a preview of what students will see for one assignment. Instructors review the recipients and grade changes, then release deliberately. Unreviewed AI feedback drafts are not sent as feedback. Students see only their own released grades; held scores stay hidden.

## Plan from the student view

**Your grade** shows released work and its calculation. In **What-if**, students can try possible scores and use **Aim for** to see what score would be needed on a chosen item for a target letter. These trial scores are private and are not saved as official grades.
